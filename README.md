# XMD / DEVELOPER — Portfolio Website

A modern, high-performance developer portfolio website built with pure semantic HTML5, CSS3, and JavaScript.

## Features
- **Neon Dark Space Aesthetic**: Deep void background (`#00040e`) with vibrant multi-layered radial lighting and ambient glows.
- **High-Fidelity Typography**: Plus Jakarta Sans & Inter typography with custom gradient headers.
- **Dual-Tone Neon Avatar**: Circular portrait frame featuring electric cyan-blue and magenta-orange glowing flares.
- **Undulating Particle Mesh Wave**: 3D particle grid mesh divider.
- **Responsive Layout**: Designed mobile-first with fluid responsiveness.

## Tech Stack
- HTML5 & CSS3 (Custom CSS Properties, CSS Grid & Flexbox)
- Vanilla JavaScript
- Local self-hosted typography (Plus Jakarta Sans, Inter)

## Deployment
